Продолжаем часть 5 SEO-плана проекта family-season: примеры сезонов по месяцам и страницы
месяцев. Сентябрь — февраль закрыты, дальше март.

## Порядок работы — строго по шагам, по одной идее за раз

1. Ты предлагаешь тему (или разбираешь мою): про что месяц, четыре недели одной строкой,
   состав семьи, чем отличается от уже имеющихся.
2. Я правлю недели и личные проекты.
3. Ты собираешь **русскую** версию и показываешь: адрес на localhost + скриншот постера.
4. Я подтверждаю или прошу правки.
5. Ты переводишь на польский и английский.
6. **Коммитишь только по моему явному «ок»/«пушь». Пуш — тоже отдельно.**
7. Когда у месяца три идеи — делаешь страницу месяца.

## Жёсткие правила — каждое стоило отладки

**Id примеров.** `public_seasons.id` — `generated by default as identity`, и люди берут номера из
той же последовательности. У примеров свой блок: `SYSTEM_ID_BASE = 1_000_000` в
`src/model/examples.ts`. Заняты смещения +1…+45, **следующие свободные +46, +47, +48** (ru, en,
pl). Только дописывать, никогда не вставлять: коды выданы навсегда. demo-1…3 остаются на 1…9.

**Переезд примера на другой id** требует сначала удалить старую строку руками: `content_key`
уникален, сид на дубле споткнётся на полпути.

**Сид отказывается писать поверх** строки с `author_key` и называет id и аккаунт.

**Что живёт в базе, а что в файле.** В базу уходит только бланк (`template`): недели, люди, цель,
тема. Слой заполнения (`fill` — настроение, проценты, итоги, фотографии) читается **из файла при
каждом рендере** по `fill_id`. Поменяли `template` — нужен `npm run db:seed`; поменяли `fill` —
достаточно перезагрузить страницу.

**Фотографии недель общие для трёх языков** (`public/examples/demo-N/week-N.svg`). Отсюда правило
адаптации: у недели с фотографией три языка обязаны рассказывать одну историю; неделя без
фотографии вправе двигаться под страну — так польская вторая неделя Экомесяца называется
«Sprzątanie Świata», а не переводится.

**Фотографии идут подряд с первой недели.** Дырка в ряду (1, 3) читается как потерянная
фотография, а не как решение.

**Полное настроение — полный ряд фотографий.** Если таблица настроения заполнена до последнего дня
месяца, фотографий должно быть четыре: месяц кончился, и три снимка из четырёх выглядят потерей.

**Подпись карточки (`summary`) — не длиннее трёх строк.** На странице месяца у неё жёсткая высота
(`page.module.css`, `.summary`), четвёртая строка обрезается. Держи 65–80 символов: 90 уже
разворачивается в четыре строки на узкой колонке.

**Палитра:** краски отсортированы по светлоте, первый человек всегда самый тёмный, последний самый
светлый. Набор с почти белой краской (`ice`, `winter`, `arctic-dawn`, `bright-night`, `cityscape`)
даёт бесцветного члена семьи — не брать, если в семье больше трёх человек. Набор, где две первые
краски почти одинаковы (`mediterranean` — два красных), не годится для семьи из двоих.

**Лимиты полей** — `src/model/limits.ts`. Проверять все три языка скриптом, не на глаз. Самое
тесное обычно `people.*.project` (22 символа) и `theme.subtitle` (26). Текст недели — 48.

**Печать ровно в 2 страницы** — обязательна, реальным PDF, на всех трёх языках, и на 31-дневном
месяце:

```bash
"/Applications/Google Chrome.app/Contents/MacOS/Google Chrome" --headless=new \
  --disable-gpu --no-pdf-header-footer --virtual-time-budget=9000 \
  --print-to-pdf=out.pdf http://localhost:3000/ru/s/<code>
grep -ao "/Count [0-9]*" out.pdf | head -1
```

Чтобы проверить 31 день, временно замени в `src/model/calendar.ts` строку
`const shift = now.getDate() < MONTH_SWITCH_DAY ? 0 : 1` на `const shift = 1` — и **верни обратно**.

**Выравнивание карточек на странице месяца** проверяется измерением, а не глазом:

```js
// playwright, из корня проекта
const boxes = await page.$$eval('main ul li > a', (n) =>
  n.map((e) => Math.round(e.getBoundingClientRect().bottom)))
```

Прогонять четыре ширины (1400, 1000, 820, 640) на всех месяцах и языках.

## Окружение

- Смотреть на `http://localhost:3000` (`npm run dev`). **`next start` подхватывает
  `.env.production.local` и ходит в боевую базу Neon** — не пользоваться им для просмотра.
- `npm run db:seed` пишет в локальный Postgres из `.env.local`.
- `e2e/site/consent.spec.ts` **флакует** — падает и на чистом дереве. Не чинить, не считать за
  регрессию.
- Перед показом: `npm run lint`, `npm run typecheck`, `npm run e2e`.
- **lint-staged может застейджить чужие правки**: смотри `git status` прямо перед `git commit`, а
  не только после `git add`. Один раз так уехал посторонний `CLAUDE.md`.

## Что править для нового примера

`src/data/examples/{ru,en,pl}/demo-N.json`, фотографии `public/examples/demo-N/week-N.svg`, реестр
`src/model/examples.ts` (`RAW` и `PUBLIC_IDS` — учти, что prettier переносит их в столбик).
**Реестр правится в том же коммите, что и файлы примера**, иначе промежуточный коммит не собирается.

## Что править для новой страницы месяца

`src/data/months/{ru,en,pl}/<slug>.json` (слаги английские: january, february, …) и `TEXTS` +
`SEASONS` в `src/model/months.ts`. Всё остальное — пункт в шапке, строка на витрине, строка на
лендинге, sitemap, hreflang — собирается из реестра само.

Карточки читаются **из базы** (`ideasByCode`), не из файлов: источник один, и правила видимости
витрины действуют. Из репозитория берётся только `summary`. Статья остаётся целой при мёртвой
базе — блок сезонов просто не рисуется.

Лид месяца пишется от настоящей проблемы этого месяца («в октябре рано темнеет», «ноябрь без
праздников», «декабрь проходит быстрее всех»), а не от календаря. **Польский лид — не перевод там,
где страна другая**: в ноябре месяц начинается со Всех Святых, и делать вид, что праздников нет,
нельзя.

## Накатить на прод

```bash
vercel env pull --environment=production .env.production.local
node --env-file=.env.production.local --import tsx tools/db/seed-examples.ts
```

Первая строка вывода должна назвать Neon, а не localhost. **Сначала сид, потом смотреть страницу
месяца** — без сида она отдаст статью и ноль карточек.

## Идеи, которые уже придуманы

Лежат в очереди, брать когда дойдём до этих месяцев:

- **Пляжный месяц** — лето. Вода, песок, загар, что делать, когда жарко и все дома.
- **Месяц огородов** — весна. Рассада на подоконнике, первая грядка, что растёт быстрее ребёнка.

Марту предложены (не утверждены): месяц уборки и выброса после зимы; месяц на улице, как только
сошёл снег; месяц женщин в семье вокруг 8 марта — не про подарки, а про рецепты и историю по
женской линии.
