# Семейный сезон

Одностраничный трекер семейного месяца: тема месяца, недели, личные проекты и настроение семьи.
Вёрстка по референс-макету, React + TypeScript + Vite, стили — CSS Modules.

## Запуск

```bash
npm install
npm run dev     # http://localhost:5173
npm run build   # прод-сборка в dist/
```

## Где что лежит

| Что | Где |
| --- | --- |
| Весь текст страницы | `src/data/content.ts` |
| Палитра, шрифты, радиусы | `src/styles/tokens.css` |
| Каркас секции (рамка + плашка) | `src/components/SectionBox.tsx` |
| Рукописные иконки (inline SVG) | `src/components/doodles/` |

## Как подставить настоящие фото недель

Положите файлы в `public/images/` и добавьте `photoSrc` в нужную карточку в `src/data/content.ts`:

```ts
{
  title: 'Неделя 1',
  lines: ['Посмотреть', 'первый фильм', 'Marvel'],
  photoAlt: 'Кадр из фильма Marvel',
  photoSrc: '/images/week1.jpg',
}
```

Без `photoSrc` в полароид-рамке рисуется плейсхолдер с подписью из `photoAlt`.

## Настроения (секция 4)

Строка настроений задаётся компактным кодом: `g` — хорошо, `y` — нормально, `r` — плохо,
`.` — пустая ячейка. Длина приводится к `DAYS_IN_MONTH` (в сентябре — 30).

Календарь заполнен наполовину: `FILLED_THROUGH_DAY = 17` в `src/data/content.ts` задаёт,
по какое число месяц закрыт. Всё после этого дня остаётся пустыми клетками, даже если
в строке кода символов больше — так календарь нельзя случайно «заполнить наперёд».
Чтобы дописать новый день: увеличьте `FILLED_THROUGH_DAY` и добавьте символ в каждую строку.
