# Семейный сезон

Постер следующего месяца вашей семьи — что ждёт вас и близких: название сезона, четыре
недели с местом под фото, личные проекты каждого и хроника настроений.

Метафора зашита в название: месяц — это сезон, недели — серии, личные проекты — сюжетные
линии, итоги — финал, а идеи на следующий месяц — анонс. Замысел простой: соберите постер
заранее, распечатайте на двух листах A4, повесьте на холодильник и проживите месяц.

На `/` — лендинг с объяснением и тремя готовыми примерами: «Месяц Человека-паука» на четверых,
«Месяц настолок» на троих и «Месяц первых раз» на пятерых — сезоны нарочно разной
прожитости, от только начавшегося до законченного, и каждый в своей теме оформления. Любой можно **форкнуть** и переписать
под свою семью, либо собрать сезон с нуля. Готовый сезон целиком помещается в ссылку:
отправили — и у близких открывается ровно тот же постер.

Страницы сайта:

| Адрес | Что |
| --- | --- |
| `/` | Лендинг: как собрать сезон и что на постере |
| `/sheet` | Постер-пример; `/sheet#data=<id>` — другой пример, `/sheet#d=…` — свой сезон |
| `/sheet/edit` | Тот же сезон в правке; без ссылки — пустой бланк |
| `/seasons` | «Мои сезоны» — заглушка будущего личного кабинета |

Next.js (App Router, бандлер Turbopack) + TypeScript, стили — CSS Modules, без внешних
зависимостей для сжатия ссылки. Сейчас всё работает на клиенте: лист живёт в хэше и до
сервера не доходит.

## Запуск

```bash
npm install
npm run dev       # http://localhost:3000
npm run build     # прод-сборка в .next/
npm run start     # прод-сервер на собранном
npm run lint
npm run typecheck
```

Серверная часть — роут-хендлеры Next в `src/app/api/`. Дымовая проверка:

```bash
curl http://localhost:3000/api/hello

```

## Два слоя: бланк и заполнение

| | Шаблон (бланк) | Заполнение |
| --- | --- | --- |
| Что это | Всё, что печатается: заголовки, тема месяца, недели, состав семьи, проекты и цели | Настроения по дням, прогресс проектов, записи в «Итогах месяца» и «Идеях на следующий месяц», фото |
| Где живёт | Только в ссылке (`#d=…`) | В локальном JSON (`src/data/examples/<id>.json`) |
| Едет в ссылку | да | нет |
| Печатается | да | нет |

Печать всегда даёт **пустой бланк**: шкалы прогресса пустые, клетки настроений пустые, поля для записи
(«Итоги месяца», «Идеи на следующий месяц») пустые, в полароид-рамке пустое место под вклейку бумажного фото. Заполняется всё руками
уже на бумаге. Заполнение существует только для примеров — чтобы показать, как выглядит
прожитый месяц. Какой набор показать, говорит пометка `data=<id>` в ссылке примера, так что
примеров со временем может стать больше одного.

## Печать: ровно две страницы A4

Лист рассчитан на две страницы, по две нумерованные секции на каждой:

| Страница | Что на ней |
| --- | --- |
| 1 | Шапка, «1. Тема месяца», «2. Недели месяца», «Наша цель на месяц» |
| 2 | «3. Личные проекты», «4. Настроение нашей семьи», «Идеи на следующий месяц» |

Свободное место на каждой странице уходит внутрь одного блока — поля для записи от руки:
на первой это рамка «Итоги месяца» внутри темы месяца, на второй — «Идеи на следующий
месяц». Остальные блоки сохраняют веб-пропорции. Раскладка проверена на худшем случае — пять человек и месяц из
31 дня — и всё равно укладывается в два листа. В диалоге печати оставьте поля по умолчанию: разметка
рассчитана на поля 10 мм (`@page` в `src/styles/print.css`).

## Как пользоваться

1. Чистый постер — **Новый сезон** в шапке сайта (или **Собрать свой сезон** на главной):
   открывается пустой сезон сразу в режиме правки.
2. Из примера — **Посмотреть пример** (это `/sheet`), затем **Форкнуть пример**: адрес
   становится `/sheet/edit#d=…`. Обе кнопки — обычные ссылки: с Cmd/Ctrl или Shift
   постер откроется в новой вкладке или окне.
3. Править текст прямо на постере: клик по любому подчёркнутому месту.
   Там же справа — кружки тем: постер можно перекрасить целиком.
4. **Скопировать ссылку** — отправить родным. У них откроется тот же постер в режиме просмотра.
5. **Печать / PDF** — печать чистого постера (в диалоге печати выбрать «Сохранить в PDF»).
6. Повесить распечатку на холодильник и прожить сезон, отмечая всё от руки.

Правки автоматически пишутся в адресную строку — ссылка и есть единственное хранилище
листа. Ничего не сохраняется ни на сервере, ни в браузере, поэтому сохраните ссылку
(в закладки или отправьте себе), прежде чем закрывать вкладку. Личный кабинет со списком
сохранённых сезонов и вход через Google или Facebook — в планах; страница «Мои сезоны»
и кнопки входа пока заглушки.

Режим виден в адресе: `/sheet#d=…` — просмотр, `/sheet/edit#d=…` — правка. Адрес правки
можно сохранить в закладки или открыть в новой вкладке — сезон откроется сразу готовым
к правке. Старые ссылки вида `/#d=…` (когда лист жил на главной) продолжают работать: они
сами уводят на `/sheet#d=…`.

Кнопки «назад» и «вперёд» работают как на обычном сайте: форк примера — это переход,
и включение правки тоже. «Назад» из правки возвращает к просмотру со всеми внесёнными
изменениями, ещё раз «назад» — к примеру, «вперёд» — обратно к сезону в том виде, в каком
его оставили. Правка текста новых записей в истории не создаёт, только обновляет ссылку.
Кнопка **К примеру** — тот же шаг назад, сезон после неё не теряется.

## Что редактируется, а что нет

Редактируется (и попадает в ссылку):

- заголовок листа и лента-девиз;
- месяц (стрелки ‹ ›), подзаголовок темы, вопрос в блоке «Итоги месяца»;
- подписи-заметки секций, названия и тексты четырёх недель;
- общая цель месяца;
- состав семьи: от 2 до 5 человек — имя, рисунок (папа / мама / сын / дочь, меняется кликом
  по аватару), название проекта, описание, личная цель;
- тема оформления — пять наборов: **Классика**, **Гранат**, **Джунгли**, **Полночь**,
  **Уголь**. Кружки справа в панели правки; выбранная тема уезжает в ссылку вместе
  с сезоном (отдельной пометкой `p=`, её видно и можно поправить руками) и печатается. Каждую тему задают две краски, остальные цвета постера —
  бумага, чернила, рамки, цвета героев — выводятся из них, поэтому темы отличаются
  целиком, а не оттенком плашек. Тема красит только постер: сайт вокруг него
  и фон страницы остаются прежними. На печати подложки не печатаются — фоном
  работает сама бумага.

Не редактируется — это каркас формы:

- номера и названия плашек («1. Тема месяца», «Идеи на следующий месяц» и т. д.);
- набор тем (их ровно пять) и то, какой цвет за какую секцию отвечает;
- рукописные иконки, легенда настроений, вёрстка и порядок секций;
- цвет человека — он выводится из рисунка (папа — синий, мама — розовый, сын — зелёный,
  дочь — оранжевый);
- количество недель (всегда 4) и число дней месяца (считается из месяца).

## Месяц подставляется сам

Новый лист берёт месяц от сегодняшней даты: **до 10-го числа — текущий месяц, с 10-го —
следующий** (лист обычно печатают заранее). Число дней в календаре настроений считается
из месяца: 28, 29, 30 или 31. Вручную месяц переключается стрелками ‹ › в режиме правки —
дни пересчитываются сами.

## Ссылка

Шаблон пакуется в компактный массив, сжимается `CompressionStream('deflate-raw')`
и кодируется в base64url — целиком в хэше, на сервер ничего не уходит. Заполненный
пример укладывается примерно в 990 символов URL, пустой лист — в 250. Если браузер
не умеет `CompressionStream`, используется несжатый запасной формат; битая ссылка
не ломает страницу — откроется демо.

Тема оформления едет рядом с блобом отдельным словом — `#d=…&p=jungle`. Её видно
в адресе и можно поменять прямо там: подставьте `classic`, `garnet`, `jungle`,
`midnight` или `coal`, и лист перекрасится без перезагрузки. Незнакомое значение
равносильно его отсутствию — тогда «Классика».

Ссылки прежних версий (`3z`/`3p`, `1z`/`1p`) открываются по-прежнему. У формата 1
темы не было вовсе, а у формата 3 она ехала внутри блоба и теперь не читается,
поэтому обе разновидности показываются в «Классике», если в адрес не дописать `p=`.
